# Screenshots

This folder holds the screenshots used by the project README.

They are generated from the `@Preview` composables in
[`app/src/main/java/com/workly/app/ui/preview/DesignPreviews.kt`](../../app/src/main/java/com/workly/app/ui/preview/DesignPreviews.kt):

1. Open that file in Android Studio.
2. Pick a preview in the **Design** pane (Home – today, Home – working now,
   Record row, Statistics card, Trend chart, Empty state).
3. Use the preview's context menu → **Save as image…**
4. Save the PNG here with the matching name, for example `home-today.png`.

For real device screenshots, run the app on a phone or emulator and use the
device's screenshot shortcut.

The previews use fixed sample data, so they are also a quick way to review the
visual language of a change without building the app.
